# ZEP: A Self-Sovereign Neobank — whitepaper

Interactive whitepaper for ZEP, the self-sovereign financial client on the Zephyrium network. Draft v0.3, November 2026.

- `index.html` — the whole paper: single file, no build step, no dependencies beyond Google Fonts. Open it in a browser or serve the folder statically.

## Structure

Abstract · 1 Introduction · 2 Design properties · 3 Identity and finance as one primitive · 4 The connector model · 5 Network architecture · 6 User-side primitives · 7 Disclosure model · 8 Economics · 9 Deployment · 10 Conclusion · References

Eight interactive figures: the seven functions of a bank, the connector model, system layers, network parameters (now vs designed), capacity at the design ceiling, the disclosure model, the issuance schedule, and deployment phases.

## Key numbers in this draft

- Supply cap 1,000,000,000 ZEP; 31,000,000 (3.1 %) created at genesis for the ICO; 969,000,000 minted block by block over 21 years, −10 % per year.
- Every block divides into three equal parts: validators, liquidity providers, DAO (the three pillars).
- Private transfer fee 0.01 ZEP. Other fees to be specified.
- Designed for up to 32 shards with 32-seat committees; the development network runs one shard.

The page is written against the Zephyrium brand book (sea green `#207B73`, Cormorant Garamond headings) and renders in light and dark themes.
